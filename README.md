# Terrastep

Android fitness territory game, built from the *Terrastep Product and Technical
Plan* v1.0 (3 Oct 2026). Walk outdoors → earn verified moving minutes → claim
H3 hexagon territory in a local league, with private-by-default fitness records.

## Status
- **Stage 1 (done):** deterministic game-rules referee + fitness math + simulation.
- **Stage 2 (done):** Postgres/Supabase schema (`server/schema.sql`) + runnable server
  (`server/app.py`) implementing all Section 16 API contracts with evidence
  verification, idempotent ingest, privacy-delayed public projections, exclusions,
  reports, export and account deletion. 19 tests passing.
- **Stage 3 (done, source-complete):** Flutter app in `app/` — onboarding
  (Section 5), Start/League/Me + Settings (Sections 6–7), API client and
  offline sync engine, and the native Kotlin tracker (foreground service,
  adaptive sampling, durable local store, Section 13). The Gradle wrapper is
  generated by the Flutter tool on first local build, or by Stage 4 CI.
- **Stage 4 (done):** GitHub Actions CI (`.github/workflows/build.yml`) that runs
  the Python suites, `flutter analyze`, and APK builds; Flutter SDK installed
  locally and the app analyzes clean ("No issues found"); genuine Gradle
  wrapper included; pilot pack in `docs/` — privacy policy draft, device
  test plan with the Section 21 quality gates, Play Store listing, Data
  safety mapping, release runbook and hardening checklist.

## Run the Stage 2 server
```bash
TERRASTEP_SECRET=dev-secret .venv/bin/python server/app.py   # http://127.0.0.1:8791
```

## Stage 1 quick start
```bash
python3 -m venv .venv
.venv/bin/pip install h3 pytest
.venv/bin/python -m pytest tests/ -q
.venv/bin/python sim/simulate.py 20
```

## Layout
- `referee/rules_v1.json` — the plan's Section 9 prototype ruleset, verbatim values.
- `referee/engine.py` — caps, 7-day linear decay, ownership with takeover margin
  and deterministic tie-breaks, territory board ranking (Sections 9–10, 17).
- `referee/fitness.py` — filtered GPS distance and MET calorie estimates (Section 12).
- `referee/h3_adapter.py` — H3 resolution-9 cells (Section 11).
- `tests/` — tests transcribed from the plan's worked examples and quality gates.
- `sim/` — multi-player season simulation harness (Section 10 scenarios).
